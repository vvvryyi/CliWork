# Персональная CRM

Локальное однопользовательское Flask-приложение для ведения клиентов, истории взаимодействий, файлов, календаря и напоминаний.

## Что уже работает

- вход по логину и паролю из `.env` с опциональной двухфакторной аутентификацией (TOTP);
- создание, поиск, алфавитная группировка и редактирование клиентов;
- безопасное архивирование клиентов с восстановлением;
- история взаимодействий с автоматической датой `ГГММДД`;
- редактирование и удаление отдельных записей истории;
- загрузка и скачивание вложений;
- подготовка сообщений для WhatsApp, Telegram, MAX, Instagram и Facebook;
- фиксация статусов «Подготовлено» и «Отправлено»;
- автоматическое планирование из записи с датой в формате `ГГММДД`;
- единый календарь клиентских и личных событий в режимах день, неделя и месяц;
- годовой календарь и планирование событий до конца 2031 года;
- счётчик просроченных событий и обзор недели с понедельника по воскресенье;
- установка как PWA без кэширования клиентских страниц;
- изменение часового пояса;
- SQLite и миграции базы данных;
- адаптивный интерфейс без внешних CDN.

## Первый запуск на Windows

Виртуальное окружение уже находится в `.venv`.

1. Откройте `.env` и обязательно замените значения:

   - `CRM_USERNAME`;
   - `CRM_PASSWORD`;
   - `SECRET_KEY`.

2. Запустите `start_crm.bat`.

3. Откройте в браузере `http://127.0.0.1:5000`.

После первого входа двухфакторную аутентификацию можно включить в разделе
«Настройки». Добавьте показанный ключ в приложение-аутентификатор и подтвердите
настройку шестизначным кодом. Перед включением сохраните резервную копию базы
`instance/crm.sqlite3`: секрет 2FA хранится в ней и нужен для последующих входов.

Запуск вручную из PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
python -m flask --app run.py db upgrade
python run.py
```

## Установка с нуля

Если каталог `.venv` отсутствует:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m flask --app run.py db upgrade
python run.py
```

## Тесты

```powershell
.\.venv\Scripts\python.exe -m pytest
```

## Развёртывание на VPS

Production-инструкция для Ubuntu, systemd, Nginx, HTTPS и Cloudflare находится в
[`deploy.md`](deploy.md). Секреты, deploy-ключ, база данных и загруженные файлы не
должны добавляться в Git.

## Локальные данные

- база: `instance/crm.sqlite3`;
- вложения: `instance/uploads/`;
- учётные данные и настройки запуска: `.env`.

`.env`, база, вложения и виртуальное окружение исключены из Git. Для полноценной резервной копии нужно сохранять всю папку `instance` вместе с `.env`.

## Важные ограничения текущей версии

- CRM открывает внешние приложения, но не отправляет сообщения через их API;
- Telegram, Instagram, Facebook и MAX могут не поддерживать автоматическую подстановку текста или файлов;
- напоминания видны внутри CRM, но фоновые системные уведомления пока не реализованы;
- текущий этап тестируется на одном Windows-компьютере.
